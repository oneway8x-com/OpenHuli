# MicroHuli hardware

The [larger battery cover](enclosure/README.md) fits the owner's measured
60 × 50 × 16 mm four-AA holder and 60 × 50 × 20 mm Nano/Hailege shield assembly.
It provides a front IR aperture and a rear bay for a future ESP-01.

Existing [robot firmware and wiring](../../firmware/MicroHuli/README.md),
[leg/horn prototypes](../../firmware/MicroHuli/hardware/horn_fit/README.md), and
[passive shoes](../../firmware/MicroHuli/hardware/feet/README.md) remain in the
imported project. The new cover does not rescale those parts or change servo pins.
